# Recuperación de Información

Este repositorio contiene las prácticas, ejercicios y actividades desarrolladas durante la asignatura de **Recuperación de Información**, como parte de mi formación en Ingeniería en Ciencias de la Computación.

## Objetivo

Aplicar y reforzar los conocimientos adquiridos durante la materia mediante el desarrollo de ejercicios prácticos, el uso de herramientas de programación y el análisis de diferentes técnicas relacionadas con la recuperación y el procesamiento de información.

## Contenido

El repositorio se actualizará progresivamente con los trabajos realizados durante el curso, incluyendo notebooks de Jupyter, implementaciones en Python, análisis de resultados y otras actividades académicas.

## Herramientas

Las herramientas y librerías utilizadas dependerán de los requerimientos de cada actividad.
